# PR 리뷰 체크리스트

PR 머지 전 아래 항목을 확인하고 체크해주세요.
최소 1명 이상의 리뷰 통과 후 머지 가능합니다.

---

## 코드 스타일 / 네이밍 컨벤션

- [ ] 변수명, 함수명이 snake_case로 작성되었는가?
- [ ] 컴포넌트명이 PascalCase로 작성되었는가? (프론트엔드)
- [ ] 불필요한 주석이 제거되었는가?
- [ ] 코드 중복 없이 간결하게 작성되었는가?

## 브랜치 네이밍

- [ ] 브랜치명이 `feature_` + snake_case 형식인가?
  - 예: `feature_backend_weather_api` ✅
  - 예: `featureWeatherApi` ❌

## 환경변수

- [ ] API 키, 비밀번호 등 민감한 정보가 하드코딩되어 있지 않은가?
- [ ] 환경변수는 `.env` 파일에만 저장되어 있는가?
- [ ] `.env` 파일이 `.gitignore`에 포함되어 있는가?

## 콘솔 로그

- [ ] `console.log` 가 제거되었는가? (프론트엔드)
- [ ] `print()` 디버그 코드가 제거되었는가? (백엔드)

## 테스트 및 검증

- [ ] 수동 테스트 결과가 PR 본문에 첨부되었는가?
- [ ] 로컬 서버 실행 후 정상 작동을 확인하였는가?
- [ ] 기존 기능이 깨지지 않았는가?

## 기타

- [ ] PR 제목이 컨벤션에 맞게 작성되었는가?
  - 예: `feat:`, `fix:`, `docs:`, `refactor:`
- [ ] 관련 이슈가 PR 본문에 연결되었는가?
  - 예: `close #15`

---

## PR 머지 기준

- 체크리스트 항목 모두 확인
- 최소 **1명 이상** 리뷰 승인
- 충돌(Conflict) 없음
