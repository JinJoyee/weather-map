# 디자인 시스템 명세서 (Design System Specification)

## 비전 및 스타일
이 디자인 시스템은 전문적이고 신뢰도가 높은 환경을 위해 구축되었습니다. 기술적 정밀함과 사용자 친화적인 접근성의 균형을 맞춘 깔끔하고 모던한 미학을 활용합니다. 시각적 언어는 짙은 파란색의 주 색상(Primary palette)을 바탕으로 따뜻한 강조색과 가독성이 뛰어난 타이포그래피 조합으로 정의됩니다.

## 색상 팔레트
색상 전략은 인터페이스 전반에 걸쳐 브랜드 컬러가 높은 무결성으로 유지되도록 하는 "충실도(Fidelity)" 접근 방식을 채택합니다.

- **Primary (#2563EB):** 주요 작업, 버튼 및 브랜드 강화를 위해 사용되는 생동감 있고 신뢰감을 주는 파란색입니다.
- **Secondary (#312E81):** 내비게이션 요소와 미묘한 UI 깊이감을 표현하는 데 사용되는 깊은 인디고(남색)입니다.
- **Tertiary (#F59E0B):** 하이라이트, 배지 및 주의를 끄는 강조 요소로 사용되는 따뜻한 호박색(Amber)입니다.
- **Neutral (#F8FAFC):** 배경 표면 및 구조적 레이아웃에 사용되는 깔끔하고 차가운 톤의 슬레이트(Slate) 색상입니다.

## 타이포그래피
이 시스템은 계층 구조를 명확히 하고 읽기 흐름을 개선하기 위해 두 가지 폰트를 조합하여 사용합니다.

- **Headlines (Manrope):** 타이틀과 히어로(Hero) 섹션에 모던하고 하이테크적인 느낌을 제공하는 기하학적 산세리프 폰트입니다.
- **Body & Labels (Inter):** 화면 성능과 기능적인 데이터 표시에 최적화된, 활용도가 높고 가독성이 매우 뛰어난 서체입니다.

## UI 로직
- **둥글기 (Level 2):** 컴포넌트들은 적당한 모서리 둥글기(Corner radii)를 가집니다. 너무 날카로운 모서리나 지나치게 둥근 알약 모양을 피하여, 친근하면서도 전문적인 느낌의 균형을 제공합니다.
- **간격 (Level 2):** 정보의 밀도를 해치지 않으면서도 충분한 여유 공간을 제공하는 표준 밀도(Density) 모델을 사용합니다. 이를 통해 데스크톱과 모바일 플랫폼 모두에서 편안한 탐색 경험을 보장합니다.
